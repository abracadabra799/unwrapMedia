# APV Content Check fixtures

Generated with `generate.py` using verified byte sequences from RFC 9924 (Advanced Professional Video) and openapv `qp_D.apv` test vectors. `default-apv1.mp4` uses standard APV in MP4 with an `apv1` sample entry and `apvC` configuration box.

Independent checks:
- `ffprobe -v error -select_streams v:0 -show_entries stream=codec_tag_string,codec_name,width,height -of compact default-apv1.mp4` reports `codec_tag_string=apv1`, `codec_name=apv`, `width=3840`, and `height=2160`.

| First sample PBU type & header | 701–704 | `01 00 01 00` (`pbu_type`=1, `group_id`=1, `reserved_zero_8bits`=0) |

Mutations generated by `generate.py`:
- `bad-signature.mp4`: byte 693..696 signature altered to `'XXXX'`.
- `bad-pbu-reserved.mp4`: PBU header byte 3 (offset 704) set to `0xFF`.
- `bad-band-reserved.mp4`: byte 707 set to `0xFF` (`band_idc`=7, `reserved_zero_5bits`=31).
- `malformed-apvc.mp4`: `apvC` box truncated to 10 bytes payload.
- `truncated-sample.mp4`: `stsz` sample 0 size set to 6 bytes.
- `many-signature-failures.mp4`: 101 samples generated with corrupted signature, for occurrence counting.

All byte offsets and field values were directly verified against file bytes.
