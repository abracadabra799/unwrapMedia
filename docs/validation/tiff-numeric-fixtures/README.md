# TIFF numeric fixtures

Generated by Pillow 11.3.0, no external copyrighted media. `default.tif` preserves default RGB writer settings. `le.tif`/`be.tif` are metadata-layout fixtures (not camera DNGs): SMinSampleValue SBYTE, SMaxSampleValue FLOAT, DNG NoiseProfile DOUBLE, and unknown private FLOAT tag. Deliberately mixed metadata tests storage types; does not claim sensor semantics/conformance.

Run `generate.py` from the repository root with Pillow 11.3.0, then `python3 docs/validation/tiff-numeric-fixtures/dump.py`. The independent struct dump records both endian orders, inline and out-of-line payloads and exact IEEE-754 bytes. Pillow's TIFF writer implements types 6 (`b`), 11 (`f`), 12 (`d`) using struct with file byte order. Reference: https://github.com/python-pillow/Pillow/blob/11.3.0/src/PIL/TiffImagePlugin.py (primary implementation).

Generated metadata and scripts are project-owned. Regeneration requires Pillow only for generation, not runtime or dump.
