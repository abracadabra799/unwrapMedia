# PNG text / ICC evidence

Generated by Pillow11.3.0 and its lcms sRGB profile generator. No user media. Run generate.py with Pillow installed, then dump.py with standard Python. dump.py independently validates CRC and zlib outputs; saved offsets/values precede application parser changes. ICC creation time can vary on regeneration, changing compressed length/offsets; tests use the checked-in fixture and regeneration requires reviewing the dump.

Reference: [W3C PNG3 §11.3.3](https://www.w3.org/TR/png-3/#11textinfo), [iCCP §11.3.2.3](https://www.w3.org/TR/png-3/#11iCCP), and §10.3. Compressed field positions in Details refer to their compressed source span, never fictitious decompressed positions in the PNG. ICC tag contents beyond the existing header decoder remain explicitly uninterpreted.

ICC structure cross-check: [ICC.1:2022 §§7.1,7.3](https://www.color.org/specification/ICC.1-2022-05.pdf) requires the128-byte header followed by a tag table beginning with a4-byte count. A128–131-byte decompressed profile is therefore incomplete even when its header size/signature agree. Header fields remain visible, with UNPARSABLE node status.
