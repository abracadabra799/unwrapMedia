# VVC (H.266) Conformance Test Fixtures

Minimal verified test fixtures for VVC (`vvc1` / `vvi1`) bitstream conformance checking in unwrapMedia.

## Standards
- ISO/IEC 14496-15: Carriage of network abstraction layer (NAL) unit structured video in the ISO base media file format (§11 VVC elementary streams)
- ITU-T Recommendation H.266 / ISO/IEC 23090-3: Versatile Video Coding (VVC)

## Provenance
Generated by `docs/validation/vvc-conformance-fixtures/generate.py` using Python standard library `struct` and validated against FFmpeg 8.1.2 / ffprobe.

Command to regenerate:
```bash
python3 docs/validation/vvc-conformance-fixtures/generate.py
```

## Fixtures

| File | Purpose | Key Byte Characteristics |
| --- | --- | --- |
| `default-vvc.mp4` | Valid baseline VVC MP4 video | 8 samples, 1920x1080, `vvc1` VisualSampleEntry, valid `vvcC` FullBox (16 bytes payload, lengthSizeMinusOne=3 -> 4 bytes length prefix, PTL present), sample 0 IDR_W_RADL (type 7), samples 1..7 TRAIL_NUT (type 0). |
| `bad-vvcc-box.mp4` | Malformed `vvcC` configuration | `vvcC` FullBox version modified to 1 (ISO/IEC 14496-15 requires version 0). |

| `bad-reserved-bit.mp4` | Reserved zero bit violation | Sample 0 NAL unit header byte 0 has bit 6 set to 1 (`nuh_reserved_zero_bit = 1`). |
| `bad-temporal-id.mp4` | Forbidden temporal ID 0 | Sample 0 NAL unit header byte 1 has bits 2..0 set to 0 (`nuh_temporal_id_plus1 = 0`, forbidden). |
| `truncated-sample.mp4` | Truncated sample in mdat | File truncated by 10 bytes; sample extent exceeds actual file length. |
| `many-nal-failures.mp4` | Bounded reporting test | 101 samples with corrupted `forbidden_zero_bit` to test 100-finding display cap and total occurrence counting. |
